# Панорама Мастер — макет сайта автосервиса

Макет главной страницы автосервиса «Панорама Мастер» (Балашиха, Соболиха / Железнодорожный).

- `index.html` — вся страница одним файлом, открывается в любом браузере.
- Плашки `[ЗАПОЛНИТЬ]` — данные, которые нужно получить от владельца (цены, стаж, гарантия, отзывы, реквизиты).
