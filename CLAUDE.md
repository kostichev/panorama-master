# Проект: «Панорама Мастер» — сайт автосервиса и автозапчастей

Автосервис и подбор запчастей для ГАЗели, Hyundai Porter, VW Transporter и легковых. Соболиха, ул. Новослободская, 50 (г.о. Балашиха). Телефон +7 (901) 711-04-11, 09:00–21:00 без выходных. Клиент Дениса, сеть «Панорама» (ещё service-panorama.ru — другой сайт, в этом чате не трогать).

## Решения владельца
- На главной обязательно видно, что мы занимаемся **автозапчастями** (подбор по VIN): заголовок «Ремонт стартеров и генераторов, замена масла и подбор автозапчастей», над ним «Автотехцентр «Панорама-Мастер»», кнопка «Подобрать запчасть» на первом экране, блок #parts сразу после первого экрана, «Запчасти» первыми в меню.
- На первом экране обязательно: «Ремонт стартеров и генераторов» и «Шиномонтаж» (кнопки под заголовком), отдельный блок #electro (стартеры/генераторы + шиномонтаж с фото) сразу после #parts.
- Записи с выбором дня/времени НЕТ — только обратный звонок: клиент звонит сам или оставляет заявку «Имя + Телефон» (обязательны во всех формах). Заявки со всех форм → MAX (бот), опционально почта. Метки `[ЗАПОЛНИТЬ]` — данные от владельца, не выдумывать.

## Устройство
- `index.html` — весь сайт одним файлом (стили и скрипты внутри), `privacy.html`, `assets/img/` (webp + jpg, по 2 размера).
- Формы шлют `POST /api/lead` (JSON: lead_type + поля формы). Типы: quick (первый экран), callback (окно «Перезвоним вам», кнопки «Обратный звонок»/«Оставить заявку»), parts, quiz, b2b, exit.
- `deploy/lead.py` — сервис заявок (Python, без зависимостей) → команда на сервере `pmaster-lead` (setup / whoami / test / last).
- `deploy/install.sh` — установка и обновление на сервере (повторный запуск безопасен).
- `deploy/enable-domain.sh ДОМЕН` — подключение домена + HTTPS + переадресация www.

## Сервер
- Общий сервер sites-1 (201.51.1.60). Сайт: `/var/www/pmaster` (git-копия ветки main), предпросмотр **http://201.51.1.60:8084**.
- Служба `pmaster-lead` (127.0.0.1:8098), настройки и токены `/etc/pmaster/lead.env` (не в git), журнал заявок `/var/lib/pmaster/leads.jsonl`.
- Конфиг nginx `panorama-master` + `/etc/nginx/snippets/pmaster-common.conf`.
- Обновить сайт после push в main: на сервере `curl -fsSL https://raw.githubusercontent.com/kostichev/panorama-master/main/deploy/install.sh | bash`.
- Репозиторий **публичный** — никаких токенов и паролей в git.

## Общий сервер sites-1 — правила
На сервере живут сайты нескольких клиентов: Якияма (yakiyama.ru, боевой — НЕ ТРОГАТЬ: /opt/yakiyama, порт 3000, никогда не запускать её setup.sh), ДэнтКо (8080), MOBA (8082), Носовихинские бани (8088, носовихинские-бани.рф), Проспект Улыбок, Gentlemen's Club, Панорама Мастер (8084).
- Трогать только свои файлы и конфиг. Чужие конфиги nginx, правила ufw, службы — не менять. Никаких `ufw reset/enable`, `apt upgrade`, перезагрузок без просьбы пользователя.
- Перед `systemctl reload nginx` — всегда `nginx -t`; ошибка → откатить только свой конфиг.
- Денис — новичок: объяснять просто, команды давать целиком, готовыми к вставке; у него Windows/PowerShell.
